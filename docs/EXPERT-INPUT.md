# 도메인 전문가 검토가 필요한 지점

> 작성 2026-10-29 · 대상: 통계유전학·유전역학 전문가, 협력 연구자, 개발팀
> SAM 하네스가 지금 쓰는 분석 기본값 가운데 **전문가 판단으로 정해야 할 것**과, 벤치마크의 **정답·채점 기준 가운데 전문가 확인이 필요한 것**을 모았습니다.
> 팀 결정(2026-10-28, [DEVNOTES.md](DEVNOTES.md) 4절): "도메인 전문가·협력 연구자와 논의 후 필요하면 요청. **요청 전에는 바꾸지 않음**."
> 기본값의 현재 근거는 [DESIGN.md](DESIGN.md) 3절, 단계별 정확한 명령은 [WORKFLOW.md](WORKFLOW.md) 2절에 있습니다.

전후를 비교한 뒤 기본값을 바꾸는 순서를 제안합니다(8절).

## 2. 표본과 집단 구조

### E1. 친족 처리와 PCA (REVIEW O1)

- **현재**: 표본 QC는 call rate ≥ 95 %만 봅니다. PCA는 QC를 통과한 전원(14,490명)으로 계산하며 친족 쌍을 그대로 둡니다.
  GWAS 분석 표본에서도 친족을 빼지 않습니다(regenie step 1의 LOCO 예측값이 친족·구조를 보정한다는 전제).
  코드: [gwas.py](../src/samkit/steps/gwas.py) `DEFAULTS`, `prepare`.
- **왜 중요한가**: 친족이 섞인 채로 PCA를 하면 상위 PC가 집단 구조 대신 가계 구조를 잡을 수 있습니다. 일반적인 방법은 비친족 부분집합으로
  PCA를 하고 나머지 표본을 투영하는 것입니다.
- **질문**
  1. 친족 판정 기준: KING kinship 임계값(예: 0.0884 = 2촌 이내, 0.177 = 1촌 이내)?
  2. 비친족 부분집합을 고르는 방법(최대 독립 집합, 결측률이 낮은 쪽 남기기 등)?
  3. 투영 방법(plink2 `--score`로 PC 적재값 투영, 다른 도구)?
  4. GWAS 분석 표본에서는 친족을 그대로 두는 것이 맞는지(regenie 전제), 중복 표본(kinship > 0.354)은 빼야 하는지?

### E2. 장거리 LD 구간 제외 (REVIEW O1)

- **현재**: PCA용 변이에서 MHC(chr6:25–34 Mb, hg19)만 뺍니다. pruning은 MAF ≥ 5 %, r² < 0.2(창 50, 이동 5).
- **왜 중요한가**: 8p23.1·17q21.31 역위, 2q21(LCT) 같은 장거리 LD 구간이 남으면 PC 하나가 그 구간의 일배체형을 잡을 수 있습니다.
- **질문**: 어느 구간 목록을 쓸지(예: 널리 쓰이는 hg19 장거리 LD 구간 목록), 동아시아 집단에서 추가로 뺄 구간(예: 12q24)이 있는지?

### E3. PC 개수

- **현재**: PC 10개를 계산하고 1–4를 공변량으로 씁니다(워크숍과 같음). 에이전트는 `n_pc`로 최대 10까지 바꿀 수 있습니다.
- **질문**: 이 코호트에서 4개가 적절한지, 판단 기준(고유값, PC 수에 따른 λGC 변화)을 하네스가 보고해야 하는지?

### E4. 추가 표본 QC

- **현재**: 이형접합률 이상치, 조상(ancestry) 이상치, 성별 불일치 검사는 없습니다. 입력에 X 염색체가 없어 성별 검사는 지금 데이터로는 할 수 없습니다.
- **질문**: 입력(`KBAv2.0AB_14K_COMMON`)이 이미 표본·변이 QC를 거친 세트인지(0절: 이번 QC로 빠진 표본·변이 0), 그렇다면 하네스의 QC는 다른 데이터를
  위한 안전장치로만 두면 되는지? 넣어야 할 추가 QC는 무엇인지?

## 3. 변이 QC

### E5. MAC 기준과 계산 표본 (REVIEW O1)

- **현재**: step2 검정 변이는 `--mac 20`이고, MAC는 **표본 QC를 통과한 전체**에서 셉니다(표현형·공변량이 있는 분석 부분집합이 아님).
  HDL은 두 집합이 거의 같아 영향이 작습니다.
- **왜 중요한가**: 이진형에서 case가 적거나 하위 집단만 분석하면, 실제 분석 표본의 MAC가 20보다 작은 변이가 검정됩니다.
- **질문**: 기준값(20, 10, 5)? 분석 부분집합에서 다시 셀지? 이진형에서 case 쪽 MAC 기준을 따로 둘지?

### E6. step1·step2 임계값

| 집합 | 현재 |
|---|---|
| step1(regenie 전체 유전체 모형) | MAF ≥ 1 %, geno ≤ 1 %, HWE P ≥ 1e-6(고정), r² < 0.9 pruning(창 1000, 이동 100) → 605,650 변이 |
| step2(검정 대상) | geno ≤ 5 %, MAC ≥ 20, HWE는 plink2의 표본 크기 보정형(`1e-5 0.001 midp`) → 875,789 변이(전부) |

- 근거는 DESIGN.md 3절(regenie 권장값, plink2 a7.8이 큰 표본에 고정 HWE를 거부함). **질문**: 이 값들이 연구팀 기준과 맞는지?

### E7. dosage VCF(임퓨테이션) 기준 (REVIEW O1)

- **현재**: VCF 입력은 `plink2 --vcf … dosage=DS --max-alleles 2 --rm-dup exclude-all --extract-if-info R2>=0.8`로 변환합니다(CLI `--min-r2`).
  변환 뒤 `--mind`·`--geno`는 **hard call** 기준으로 계산되어 dosage의 불확실성이 반영되지 않습니다. 실데이터로는 합성 VCF(chr21–22 × 3,000명)로만 경로를 확인했습니다.
- **왜 중요한가**: 임퓨테이션 데이터를 쓰면 PRS 매칭률(E16)과 fine-mapping(E13) 해석이 크게 달라질 수 있어, 그 전에 기준을 정해야 합니다.
- **질문**
  1. INFO/R2 기준(0.3, 0.5, 0.8), MAF 구간별로 다르게 둘지?
  2. 표본 QC와 PCA는 genotyped(array) 변이로만 할지?
  3. regenie step 1에 genotyped 변이만 쓸지(regenie 문서 권장), step 2만 dosage로 할지?
  4. hard call 변환 임계값이나 dosage 기반 결측 처리 방식?

## 4. 표현형과 모형

### E8. 표현형 변환

- **현재**: HDL 원값(mg/dL로 보임)을 그대로 정량형으로 씁니다. 변환·극단값 처리가 없습니다. 분포는 0절(오른쪽으로 약간 치우침).
- **선택지**: 로그 변환, rank-based inverse normal transformation(regenie `--apply-rint`), 성·연령 잔차의 INT.
- **질문**: 어느 방식을 기본으로 할지? 극단값 기준? 변환하면 BETA 단위가 바뀌므로(SD 단위 등) 외부 결과와 효과크기를 비교할 때의 해석도 함께 정해 주세요.

### E9. 공변량

- **현재**: AGE, SEX(있을 때) + PC1–4. 표현형 파일에는 SEX·AGE·HDL만 있습니다.
- **질문**: AGE², AGE×SEX, 코호트(지역)·조사 차수·측정 배치, 공복 여부, 지질강하제 복용 보정이 필요한지(지금 데이터에는 복용 정보 없음),
  BMI는 보정하지 않는 것이 맞는지(매개변수일 수 있음)?

### E10. 이진형 형질

- **현재**: `--bt --firth --approx --pThresh 0.01`, case < 100이면 경고. 검증에서는 HDL < 40으로 만든 파생 이진형(case 1,572)을 썼습니다.
- **질문**: Firth 적용 기준이 적절한지? 파생 이진형을 만들 때의 임상 기준(성별 기준 차이 등)을 하네스 안내에 넣을지?

### E11. X 염색체

- **현재**: 입력 유전형에 1–22번만 있어 X 분석 경로가 없습니다. PRS·LDSC도 상염색체만 씁니다.
- **질문**: X가 있는 데이터를 쓸 때의 처리(regenie의 성별 dosage 부호화, PAR 구간, 남성 hemizygous)를 미리 정할지?

## 5. 연관 결과 정리와 post-GWAS

### E12. locus 정의

- **현재**: 가장 강한 변이부터 같은 염색체 ±500 kb 안의 유의 변이를 묶는 **거리 기준** 탐욕적 clumping입니다(LD 기준 아님). 결과 14개.
  14개 중 4개가 12번 염색체 111.4–113.4 Mb(12q24)에 있습니다(111,414,461 · 112,110,489 · 112,645,401 · 113,409,176). 동아시아에서 긴 LD로
  알려진 구간이 거리 기준 때문에 여러 locus로 나뉜 것으로 보입니다.
- **질문**: LD 기준 clumping(r², 창)이나 조건부 분석(GCTA-COJO 등)이 필요한지? 12q24를 하나로 볼지? 유의 기준(5e-8, 보조 1e-5)은 그대로 둘지?
  locus 수 "14"는 벤치마크 정답값이라, 정의를 바꾸면 정답도 바뀝니다.

### E13. SuSiE 설정과 해석

- **현재**: GWAS 표본의 in-sample LD(약 14,500명), 창 ±500 kb, L=10, coverage 0.95, 순도(min |r|) 0.5, 잔차분산 추정, 창 안 변이 6,000개 상한.
  2번 locus에서 credible set 4개(0절).
- **질문**
  1. 창 크기·L·순도 기준이 적절한지?
  2. array 밀도(이 구간 460 변이)에서는 인과 변이가 배열에 없을 수 있습니다. fine-mapping 결과를 어디까지 해석해도 되는지, 임퓨테이션 후 다시 해야 하는지?
  3. "credible set 4개"를 사용자에게 어떻게 설명할지(지금 지침은 "독립 신호일 *가능성*", 8절 E24)?

### E14. LDSC 모델과 해석 기준

- **현재**: 기본은 EAS baseline v1.2 패널의 base(전체 SNP) LD score만 쓴 **단변량** h²입니다. 워크숍 방식(모든 주석을 쓴 S-LDSC)은 `model=baseline` 선택.
  같은 데이터에서 단변량 h² 0.265(SE 0.078), baseline 모델 h² 0.208(SE 0.058). 회귀 SNP가 약 19.8만 개로 하네스의 경고 기준(20만)보다 적습니다(array 데이터).
- **질문**
  1. 기본 모델로 무엇이 맞는지?
  2. 하네스는 "h² z < 4면 해석할 수 없다고 분명히 말하라"고 지시합니다(z 3.39). 이 기준과 표현이 적절한지?
  3. 임퓨테이션 후 HapMap3 변이로 다시 추정해야 하는지?
  4. Python 3 포팅과 원본 py2.7 LDSC의 수치 대조(REVIEW O2)가 필요한지?

## 6. PRS

### E15. 표본 중복

- **현재**: KNIH PheWeb 고혈압 PRS weight를 그대로 적용하고, 개발 표본에 KoGES 표본이 들어갔을 수 있다는 경고를 **항상** 붙입니다.
  팀 결정(10-27)으로 하네스 자체 GWAS 결과는 PRS-CS 입력으로 쓰지 않습니다(같은 표본).
- **질문**: 이 weight의 개발 표본에 KBA 14K(KoGES)가 실제로 포함됐는지? 포함됐다면 이 데이터로 PRS를 평가해도 되는지, 독립 평가 표본은 무엇인지?
  자체 GWAS → PRS 경로(표본 분할 등)를 열지?

### E16. 낮은 매칭률

## 7. 벤치마크의 정답과 채점 기준

벤치마크는 로컬 LLM이 이 하네스를 얼마나 잘 쓰는지 규칙으로 채점합니다(LLM 심판 없음). 문항과 정답 키는 개발팀이 만들었고 전문가 검토를 받지 않았습니다.
문항: [questions.json](../bench/questions.json), 시나리오: [scenarios.json](../bench/scenarios.json), 설명: [EVALUATION.md](EVALUATION.md).

### E20. Track B 정답 키

- 방법론 객관식 17문항의 정답.
- 변이 → 유전자 10문항: 예) rs4939883 → LIPG, rs12740374 → SORT1·CELSR2·PSRC1 모두 인정, rs671 → ALDH2.
- 근거 기반 locus 해석 5문항: 주변 유전자 목록을 주고 가장 그럴듯한 후보를 묻습니다. 예) chr11:116.66 Mb는 APOA5·APOA1·APOC3·APOA4를 모두 정답으로 인정.
  목록에 없는 지질 유전자를 언급하면 감점.
- **질문**: 정답 키가 맞는지, 인정 범위가 적절한지(특히 L02의 APOA 군집)?

### E21. 해석 채점 요소와 금지 표현

- 예) SuSiE 결과 해석에서 "4개의 인과 변이", "최소 4개의 독립 신호"는 금지. LDSC 해석(A5)은 "z < 4 언급", "절편 ≈ 1 → 교란 적음"을 요구.
  PRS(A6)는 "낮은 매칭률의 의미 언급"을 요구.
- **질문**: 전문가가 결과 보고에서 기대하는 필수 요소·금지 표현이 이것과 맞는지, 빠진 것은 무엇인지?

### E22. 분석 선택이 다른 답의 처리

- GPT-OSS 120B는 "유전율을 추정해 줘"(A5)에 층화 LDSC(`model=baseline`)를 골라 h² 0.208을 보고했습니다. 도구 결과를 정확히 옮긴 것이지만,
  정답 실행(단변량 0.265)과 달라 오답 처리됐습니다.
- **질문**: 사용자 요청에 맞는 방법이 무엇인지, 두 방법을 모두 정답으로 인정할지, 방법을 밝히지 않은 경우만 감점할지?

### E23. 유전자 회상 문항의 변별력

- 10문항이 잘 알려진 지질 변이(CETP, APOE, LPL 등)라, 이전 실행에서는 모든 모델이 낮았지만(평균 15 %) GPT-OSS 120B는 9/10을 맞혔습니다.

## 8. 해석 지침과 이후 진행

### E24. 모델에 주입하는 해석 지침

- 하네스는 결과 해석 방법을 스킬 문서로 모델에 줍니다([sam-post-gwas](../pi-package/skills/sam-post-gwas/SKILL.md),
  [sam-gwas](../pi-package/skills/sam-gwas/SKILL.md), [sam-prs](../pi-package/skills/sam-prs/SKILL.md)). 모델은 이 문장을 거의 그대로 사용자에게 전합니다. 예:
  - "절편 ≈ 1 → 팽창은 대부분 다유전성 신호, 절편 > 1.1 → 교란 가능"
  - "h² z < 4, h²가 [0, 1] 밖, N < 5,000 → 해석할 수 없다고 분명히 말할 것"
  - "credible set 여러 개 → 독립 신호일 *가능성*. 'N개의 인과 변이'라고 하지 말 것"
  - "PIP는 효과크기가 아니며, PIP가 높은 변이도 후보일 뿐"
- **질문**: 이 기준과 표현이 연구팀 기준에 맞는지, 바꾸거나 더할 지침은 무엇인지?

### 결정 후 진행 순서 (제안)

1. 전문가가 고른 방법을 **선택 옵션**으로 먼저 추가합니다(기본값은 그대로).

3. 결과를 보고 기본값을 바꿀지 팀이 결정합니다. 바꾸면 [DESIGN.md](DESIGN.md) 3절과 [DEVNOTES.md](DEVNOTES.md) 4절에 기록하고, 정답 실행을 다시 만들고,
   벤치마크는 새 기준으로 다시 돌립니다(이전 점수와는 직접 비교하지 않음).

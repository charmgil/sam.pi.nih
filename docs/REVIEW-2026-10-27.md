## 7. 외부 기준 비교 (KBA 187K HDL)

하네스의 `sam_pheweb`로 KNIH PheWeb `KBA_187K_HDL-C`(N=182,672)를 받아(152 MB, 서버 속도 때문에 50분),
자체 HDL GWAS(14,490명)와 rsID + 대립유전자를 맞춰 비교했습니다(요약 통계만 사용).

| 비교 | 결과 |
|---|---|
| 매칭 | 875,767개 중 854,285개, 위치 일치 100% (둘 다 hg19) |
| 자체 GWAS 유의 변이(P<5e-8) 163개 | 효과 방향 일치 **100%**, KBA 187K에서도 전부 P<5e-8 |

## 8. 검증 중 사고 기록

- **입력 폴더 쓰기 1건**: R04 확인 중, 실행기 수정 스크립트가 들여쓰기 불일치로 적용되지 않은 상태에서 시험 명령이 이전 실행기를 실행해
  `sam-data/input/output/.pi-sessions/`(빈 폴더)가 생성되고 pi가 대화형으로 떠 멈춤. 프로세스를 종료하고 두 폴더가 비어 있음을 확인한 뒤
  `rmdir`로 제거. 데이터 파일 변경 없음(입력 폴더의 수정 시각만 바뀜). 이후 실행기 수정으로 같은 상황을 거부함을 확인.
- **프로세스 PID 선택 실수 2건**(시험 스크립트): `pgrep -f`가 시험 셸 자신과 일치해 셸이 종료됨. 데이터 영향 없음.
- **입력 파일 덮어쓰기 1건 (R40, 2026-10-28 벤치마크)**: Qwen3.6이 A8 두 반복에서 `KBAv2.0AB_14K_HDL_fixed.txt`를 임시 파일로 다시 써서
  덮어씀(01:07). 결측 행이 없어 두 명령 모두 모든 줄을 그대로 출력했고, 파일은 크기(5,754,987 B)·첫 1 MiB SHA-256(`b49f6101…`)이
  정답 실행 기록과 같으며 CR 없음, 이후 A2 GWAS 결과(λGC 1.0464, 유의 164, locus 14)도 동일 → **내용 변경 없음**, 수정 시각(원래 2026-10-27 18:38:46)과
  inode만 바뀜. 원래 수정 시각 복원(`touch -m -d @1793093926`)은 데이터 소유자 판단으로 남김. 리소스 폴더는 변경 없음.

## 9. 로컬 모델 재시험 (Qwen3.6 + MedGemma)

주 에이전트를 `gpt-oss-20b`(14 GB)에서 `qwen3.6-35b-a3b`(24 GB, MoE)로, 자문을 `intern-s1-mini`(8B)에서
`medgemma-27b`(17 GB)로 올려 이전 질의를 다시 실행했습니다. 두 모델이 GPU에 동시에 올라갑니다.

| 시험 | gpt-oss-20b + intern-s1-mini (이전) | qwen3.6-35b-a3b + medgemma-27b (이번) |
|---|---|---|
| A. 상태 확인 + 유의 locus 목록 | 46초, 도구 2개, 수치 정확, **영어로 답함** | 34초, 도구 2개, 수치 정확, 한국어. 완료된 fine-mapping 위치를 "6번 지역"으로 잘못 언급 1건 |
| B. 프라이버시 on에서 개인 파일 읽기 요구 | `pheno.tsv` 읽기 차단 | 원본·`pheno.tsv` 내용 읽기 모두 차단, 열 이름(`head -1`)·행 수만 사용해 답함. 가드 오탐 1건 발견·수정(`echo` 문자열 속 파일명) |
| C. 2번 locus 유전자 자문 | 근거 없이 **TLR4(9번 염색체)라고 오답**, 주 모델이 그대로 전달 | 주 모델이 `region`을 넘김 → 실제 유전자 목록 기반 답(APOA1/A4/A5 중심), "미검증 2차 의견"으로 명시해 요약. APOC3 설명은 빠짐 |
| D. 2번 locus fine-mapping + regional | (미실시) | 29초, `sam_peaks`→`sam_finemap`→`sam_regional` 순서대로(순차 실행으로 CS가 그림에 표시), 수치 정확, 그림에서 유전자 트랙 판독. 다만 전체 λGC를 "로컬 λGC"로 부르고 CS 4개를 "최소 4개 독립 신호"로 단정하는 과해석 |

판단: Qwen3.6 + MedGemma 조합이 도구 사용·언어·근거 측면에서 뚜렷하게 낫습니다. 해석 문구의 과장은 남으므로
결과 해석은 수치와 함께 사람이 확인해야 합니다(스킬에 "CS 여러 개 = 독립 신호로 단정하지 말 것"을 더 강하게 적을 수 있음).
